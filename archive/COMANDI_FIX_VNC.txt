================================================================================
FIX VNC - COMANDI DA ESEGUIRE
================================================================================

Il problema è che il desktop non si avvia. Esegui questi comandi:

1. KILL SESSIONI ESISTENTI:
--------------------------------------------------------------------------------
vncserver -kill :1
vncserver -kill :2

2. INSTALLA XFCE (se non installato):
--------------------------------------------------------------------------------
sudo apt install -y xfce4 xfce4-goodies

3. CREA XSTARTUP CORRETTO:
--------------------------------------------------------------------------------
cat > ~/.vnc/xstartup << 'EOF'
#!/bin/bash
export XKL_XMODMAP_DISABLE=1
unset SESSION_MANAGER
unset DBUS_SESSION_BUS_ADDRESS

[ -x /etc/vnc/xstartup ] && exec /etc/vnc/xstartup
[ -r $HOME/.Xresources ] && xrdb $HOME/.Xresources

xsetroot -solid grey
vncconfig -iconic &

export XDG_CURRENT_DESKTOP="XFCE"
export XDG_MENU_PREFIX="xfce-"
export XDG_SESSION_DESKTOP="xfce"

startxfce4 &
EOF

chmod +x ~/.vnc/xstartup

4. AVVIA VNC:
--------------------------------------------------------------------------------
vncserver :1 -geometry 1280x720 -depth 24 -localhost no

5. VERIFICA:
--------------------------------------------------------------------------------
vncserver -list

================================================================================
OPZIONE ALTERNATIVA (Desktop minimale):
================================================================================

Se XFCE non funziona, prova con desktop minimale:

vncserver -kill :1
cat > ~/.vnc/xstartup << 'EOF'
#!/bin/bash
unset SESSION_MANAGER
unset DBUS_SESSION_BUS_ADDRESS
[ -x /etc/vnc/xstartup ] && exec /etc/vnc/xstartup
[ -r $HOME/.Xresources ] && xrdb $HOME/.Xresources
xsetroot -solid grey
vncconfig -iconic &
xterm -geometry 80x24+10+10 -ls -title "$VNCDESKTOP Desktop" &
twm &
EOF
chmod +x ~/.vnc/xstartup
vncserver :1 -geometry 1280x720 -depth 24 -localhost no
