🚀 QUICK START
================================================================================

ARCHITETTURA:
  - TUTTO sull'AI Accelerator (Linux remoto)
  - Da Windows: solo browser → http://AI_ACCELERATOR_IP:5000

1. DEPLOY DA WINDOWS (prima volta)
   
   # Con Git Bash/WSL
   export AI_ACCELERATOR_IP=192.168.1.100
   export AI_ACCELERATOR_USER=user
   bash deploy_vision_completo.sh
   
   # Oppure copia file manualmente via WinSCP

2. INSTALLAZIONE DIPENDENZE SU AI ACCELERATOR (prima volta)
   
   # Python packages
   pip install ultralytics opencv-python numpy
   
   # ROS2 packages
   sudo apt install ros-humble-cv-bridge ros-humble-vision-msgs
   
   # Camera Orbecc driver
   cd ~/ros2_ws/src
   git clone https://github.com/orbbec/OrbbecSDK_ROS2.git
   cd ~/ros2_ws
   colcon build --packages-select orbecc_camera
   source install/setup.bash

3. TEST SISTEMA SU AI ACCELERATOR
   
   # SSH su AI Accelerator
   ssh user@192.168.1.100
   cd ~/MekoAiAccelerator
   python3 test_vision_system.py

4. AVVIO SISTEMA SU AI ACCELERATOR
   
   # SSH su AI Accelerator
   ssh user@192.168.1.100
   cd ~/MekoAiAccelerator
   bash avvia_sistema_completo.sh
   
   # TUTTO si avvia: Vision + Robot + Web Interface

5. USO DA WINDOWS
   
   # Apri browser:
   http://192.168.1.100:5000
   
   # Fatto! Sistema pronto

4. VISUALIZZA DETECTIONS
   
   # Monitor detections
   ros2 topic echo /vision/detections_3d
   
   # Visualizza video annotato
   ros2 run rqt_image_view rqt_image_view /vision/annotated_image

5. PICK OGGETTO (manuale)
   
   # Seleziona bottiglia
   curl -X POST localhost:5000/api/vision/select_class -d '{"class":"bottle"}'
   
   # Pick
   curl -X POST localhost:5000/api/vision/pick_target

6. STOP SISTEMA
   
   bash ferma_vision_robot_system.sh

📊 ROS2 TOPICS
================================================================================

PUBBLICATI:
  /vision/detections          - Detections 2D (vision_msgs)
  /vision/detections_3d       - Detections 3D + coordinate (JSON)
  /vision/annotated_image     - Video con bounding boxes
  /vision/selected_target     - Target selezionato (PoseStamped)
  /vision/system_status       - Status sistema
  /vision/controller_status   - Status controller
  /vision/coordinator_response - Risposte comandi

SOTTOSCRITTI:
  /camera/color/image_raw     - RGB camera
  /camera/depth/image_raw     - Depth camera
  /camera/color/camera_info   - Camera intrinsics
  /vision/coordinator_command - Comandi sistema

================================================================================
🔍 TROUBLESHOOTING
================================================================================

Camera non funziona:
  → lsusb | grep Orbbec
  → ros2 topic list | grep camera
  → ros2 launch orbecc_camera gemini_330_series.launch.py

YOLO troppo lento:
  → export YOLO_MODEL=yolov8n.pt
  → Usa modello nano (più veloce)

Robot non risponde:
  → ping 192.168.10.194
  → python3 remote_ur_control/check_robot_status.py
  → Verifica External Control URCap attivo

Vision nodes non partono:
  → source /opt/ros/humble/setup.bash
  → export PYTHONPATH=$(pwd):$PYTHONPATH
  → Riavvia sistema
