================================================================================
🚀 3 PASSI PER INIZIARE
================================================================================

┌────────────────────────────────────────────────────────────────────────────┐
│ PASSO 1: DEPLOY (solo prima volta)                                        │
└────────────────────────────────────────────────────────────────────────────┘

Da Windows (usa Git Bash o WSL):

  1. Apri terminale Git Bash o WSL
  
  2. Vai nella directory progetto:
     cd /path/to/MekoAiAccelerator
  
  3. Configura IP AI Accelerator:
     export AI_ACCELERATOR_IP=192.168.1.100    # ← MODIFICA CON IP REALE
     export AI_ACCELERATOR_USER=user           # ← MODIFICA USERNAME
  
  4. Esegui deploy:
     bash deploy_vision_completo.sh
  
  ✅ Tutti i file verranno copiati sull'AI Accelerator


┌────────────────────────────────────────────────────────────────────────────┐
│ PASSO 2: AVVIA SISTEMA (ogni volta che vuoi usarlo)                       │
└────────────────────────────────────────────────────────────────────────────┘

Su AI Accelerator (via SSH):

  1. Connettiti via SSH:
     ssh user@192.168.1.100
  
  2. Vai nella directory:
     cd ~/MekoAiAccelerator
  
  3. Avvia TUTTO:
     bash avvia_sistema_completo.sh
  
  ✅ Si avviano automaticamente:
     • Camera Orbecc
     • Vision YOLO Detector
     • Motion Planning
     • Robot Controller
     • Web Interface


┌────────────────────────────────────────────────────────────────────────────┐
│ PASSO 3: USA DA WINDOWS (apri solo il browser!)                           │
└────────────────────────────────────────────────────────────────────────────┘

  1. Apri browser (Chrome/Firefox/Edge)
  
  2. Vai all'indirizzo:
     http://192.168.1.100:5000
     
     (sostituisci 192.168.1.100 con IP reale AI Accelerator)
  
  ✅ Vedrai web interface con:
     • Video feed camera con detections
     • Lista oggetti rilevati
     • Controlli per pick/stop robot


================================================================================
🎮 COME USARE
================================================================================

Dalla web interface nel browser:

  1. VISUALIZZA DETECTIONS
     → Vedi video camera con bounding boxes YOLO
     → Lista oggetti rilevati in tempo reale
  
  2. SELEZIONA OGGETTO
     → Digita classe oggetto (es: "bottle", "cup", "phone")
     → Click "Select Class"
  
  3. PICK OGGETTO
     → Click "Pick Target"
     → Robot si muove automaticamente verso oggetto
  
  4. STOP EMERGENZA
     → Click "Stop Robot" per fermare

================================================================================
❓ TROUBLESHOOTING
================================================================================

PROBLEMA: Deploy non funziona
SOLUZIONE: 
  • Verifica connessione: ping 192.168.1.100
  • Verifica SSH: ssh user@192.168.1.100
  • Usa deploy manuale con WinSCP se necessario

PROBLEMA: Web interface non raggiungibile
SOLUZIONE:
  • Verifica sistema avviato su AI Accelerator
  • Verifica URL corretto: http://AI_IP:5000
  • Verifica firewall: sudo ufw allow 5000/tcp

PROBLEMA: Camera non funziona
SOLUZIONE:
  • SSH su AI Accelerator
  • Verifica USB: lsusb | grep Orbbec
  • Verifica driver: ros2 topic list | grep camera

PROBLEMA: Robot non risponde
SOLUZIONE:
  • Verifica robot acceso
  • Verifica IP: ping 192.168.10.194
  • Verifica controller attivo su teach pendant
