================================================================================
PROBLEMA IDENTIFICATO:
================================================================================

Il robot UR5e richiede che sia in "Remote Control mode" per accettare 
comandi remoti come "power on". Questo è un requisito di sicurezza.

SOLUZIONE:
----------

Per abilitare Remote Control sul robot:

1. VIA VNC (raccomandato):
   - Connettiti via VNC: vncviewer 192.168.10.194:5900
   - Sul Teach Pendant virtuale, vai su:
     Settings > System > Remote Control
   - Attiva "Remote Control"
   - Riconnetti al Dashboard Server (porta 29999)

2. VIA TEACH PENDANT FISICO:
   - Sul Teach Pendant fisico, vai su:
     Settings > System > Remote Control
   - Attiva "Remote Control"

DOPO AVER ATTIVATO REMOTE CONTROL:
-----------------------------------

Il comando power_on funzionerà correttamente. Il robot accetterà:
- power on
- brake release
- play
- stop
- pause
- load program

================================================================================
VERIFICA CHE POWER_ON FUNZIONI:
================================================================================

Dopo aver attivato Remote Control, esegui di nuovo:

python verifica_vnc_e_poweron.py

Dovresti vedere:
- [OK] Comando accettato
- [SUCCESS] POWER ON FUNZIONA! Robot acceso con successo!

================================================================================
NOTA IMPORTANTE:
================================================================================

Il comando power_on nella web interface funzionerà SOLO se:
1. Il robot è in Remote Control mode
2. La connessione al Dashboard Server è attiva
3. Il robot non ha errori di sicurezza

Se il robot non è in Remote Control mode, il comando verrà rifiutato
per motivi di sicurezza (comportamento normale e corretto).
