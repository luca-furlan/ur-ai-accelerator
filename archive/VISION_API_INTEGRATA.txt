✅ ENDPOINT ESISTENTI (funzionano come prima):

  POST /api/movej                     - Movimento joint
  POST /api/stop                      - Stop robot
  POST /api/speedj                    - Velocità joint
  POST /api/speedl                    - Velocità lineare
  POST /api/servoj                    - Servo joint
  ... (tutti gli altri endpoint esistenti)

✅ NUOVI ENDPOINT VISION (aggiunti):
  GET  /api/vision/status             - Status sistema vision
  GET  /api/vision/detections         - Detections real-time
  POST /api/vision/start              - Avvia vision system
  POST /api/vision/stop               - Ferma vision system
  POST /api/vision/pick_target        - Pick oggetto rilevato
  POST /api/vision/select_class       - Seleziona classe target
  GET  /api/vision/camera/info        - Info camera
