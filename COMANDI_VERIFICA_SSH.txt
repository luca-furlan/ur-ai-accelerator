================================================================================
COMANDI PER VERIFICARE SSH SULLA MACCHINA AI ACCELERATOR
================================================================================

Esegui questi comandi direttamente sulla macchina (monitor + tastiera):

--------------------------------------------------------------------------------
1. VERIFICA STATO SERVIZIO SSH
--------------------------------------------------------------------------------

sudo systemctl status ssh

# Output atteso se SSH è ATTIVO:
#   ● ssh.service - OpenBSD Secure Shell server
#      Loaded: loaded (...)
#      Active: active (running) since ...
#      Main PID: <numero> (sshd)
#      Status: "sshd: accepting connections"

# Output se SSH NON è attivo:
#   Active: inactive (dead)


--------------------------------------------------------------------------------
2. VERIFICA SE PORTA 22 È IN ASCOLTO
--------------------------------------------------------------------------------

sudo ss -tlnp | grep :22

# Output atteso se SSH funziona:
#   LISTEN  0  128  0.0.0.0:22  0.0.0.0:*  users:(("sshd",pid=<numero>,fd=3))

# Se non vedi output, SSH non è in ascolto


# Alternativa:
sudo netstat -tlnp | grep :22


--------------------------------------------------------------------------------
3. VERIFICA PROCESSI SSH
--------------------------------------------------------------------------------

ps aux | grep sshd | grep -v grep

# Output atteso:
#   root    <pid>  ... /usr/sbin/sshd -D
#   root    <pid>  ... sshd: /usr/sbin/sshd -D [listener] 0 of 10-100 startups


--------------------------------------------------------------------------------
4. VERIFICA IP DELLA MACCHINA
--------------------------------------------------------------------------------

hostname -I

# Dovrebbe mostrare: 192.168.10.191
# Se mostra un IP diverso, quello è il problema!


# Alternativa:
ip addr show | grep "inet "


--------------------------------------------------------------------------------
5. TEST CONNESSIONE SSH LOCALE
--------------------------------------------------------------------------------

ssh lab@localhost

# Se funziona, vedrai:
#   lab@localhost's password:
#   (inserisci: easybot)

# Se NON funziona, vedrai:
#   ssh: connect to host localhost port 22: Connection refused


--------------------------------------------------------------------------------
6. VERIFICA LOG SSH (se ci sono errori)
--------------------------------------------------------------------------------

sudo journalctl -u ssh -n 50

# Mostra gli ultimi 50 messaggi del servizio SSH
# Cerca errori o messaggi importanti


--------------------------------------------------------------------------------
7. VERIFICA CONFIGURAZIONE SSH
--------------------------------------------------------------------------------

sudo sshd -t

# Se non ci sono errori, non mostra nulla
# Se ci sono errori, li mostra


--------------------------------------------------------------------------------
8. VERIFICA FIREWALL
--------------------------------------------------------------------------------

sudo ufw status

# Se firewall è attivo, verifica che permetta SSH:
#   To                         Action      From
#   --                         ------      ----
#   22/tcp                     ALLOW       Anywhere

# Se SSH non è permesso:
sudo ufw allow 22/tcp
sudo ufw reload

================================================================================
SE SSH NON È ATTIVO - COMANDI PER AVVIARLO
================================================================================

# Avvia SSH
sudo systemctl start ssh

# Abilita SSH al boot
sudo systemctl enable ssh

# Verifica di nuovo
sudo systemctl status ssh


================================================================================
SE SSH NON È INSTALLATO - INSTALLAZIONE
================================================================================

# Installa SSH
sudo apt update
sudo apt install -y openssh-server

# Avvia e abilita
sudo systemctl start ssh
sudo systemctl enable ssh

# Verifica
sudo systemctl status ssh
