================================================================================
AVVIA WEB INTERFACE - ISTRUZIONI MANUALI
================================================================================

La web interface deve essere avviata SULL'AI ACCELERATOR.

================================================================================
PASSO 1: Connettiti
================================================================================

    ssh lab@192.168.10.191

================================================================================
PASSO 2: Vai nella directory
================================================================================

    cd ~/MekoAiAccelerator

================================================================================
PASSO 3: Ferma processi esistenti
================================================================================

    pkill -9 -f web_interface
    sleep 2

================================================================================
PASSO 4: Avvia Web Interface
================================================================================

    export UR_ROBOT_IP=192.168.10.194
    export WEB_PORT=8081
    export WEB_HOST=0.0.0.0
    python3 -m remote_ur_control.web_interface

OPPURE in background:

    nohup python3 -m remote_ur_control.web_interface > /tmp/web_interface.log 2>&1 &

================================================================================
PASSO 5: Verifica
================================================================================

Dovresti vedere:
    🌐 Starting web interface on http://0.0.0.0:8081
    * Running on http://192.168.10.191:8081

================================================================================
PASSO 6: Apri Browser
================================================================================

    http://192.168.10.191:8081

================================================================================
COSA VEDRAI
================================================================================
