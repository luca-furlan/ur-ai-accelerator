🔍 COME FUNZIONA EXTERNAL CONTROL URCAP
================================================================================

Secondo la documentazione ufficiale Universal Robots:

1. Il ROBOT apre un SERVER sulla porta 50002
2. Il ROBOT ASPETTA connessioni dalla macchina remota
3. La MACCHINA REMOTA si connette AL ROBOT sulla porta 50002

QUINDI:
- Robot (194) = SERVER (ascolta sulla porta 50002)
- Macchina Remota (191) = CLIENT (si connette al robot)

================================================================================
❓ ALLORA PERCHÉ SUL TEACH PENDANT CHIEDONO "HOST IP"?
================================================================================

Il campo "Host IP" sul Teach Pendant potrebbe essere:
- L'IP della macchina remota (191) - per qualche verifica o log
- OPPURE
- Un campo che non viene usato realmente

MA LA CONNESSIONE FUNZIONA COSÌ:
- Il robot ascolta sulla porta 50002
- La macchina remota si connette al robot

================================================================================
🔧 SE IL ROBOT DICE "NON RIESCE A CONNETTERSI"
================================================================================

Se il robot dice che non riesce a connettersi a 191:50002, significa che:
- Il robot STA PROVANDO a connettersi alla macchina remota
- Ma la macchina remota NON è in ascolto sulla 50002

SOLUZIONE:
1. Avvia il driver ROS2 sulla macchina remota PRIMA
2. Il driver ROS2 si metterà in ascolto sulla 50002
3. POI avvia il programma sul robot

OPPURE:

1. Prova a mettere Host IP vuoto o IP robot (194)
2. Il robot dovrebbe aspettare connessioni invece di provare a connettersi
