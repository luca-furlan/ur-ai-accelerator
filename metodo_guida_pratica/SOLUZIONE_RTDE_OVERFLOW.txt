================================================================================

PROBLEMA 1: RTDE Pipeline Overflow
-----------------------------------
Errore: "Pipeline producer overflowed! <RTDE Data Pipeline>"

CAUSA:
Il robot invia dati troppo velocemente per il driver ROS2.

SOLUZIONE:
Ridurre la frequenza di aggiornamento RTDE o ottimizzare il sistema.

PROBLEMA 2: Errore Compilazione Teach Pendant
----------------------------------------------
Se c'è un errore di compilazione sul Teach Pendant, il programma non può partire.

SOLUZIONE:
Correggere l'errore di compilazione nel programma.

PASSO 3: RIDUCI FREQUENZA RTDE
-------------------------------
Il problema RTDE overflow può essere risolto riducendo la frequenza.

Opzione A: Modifica configurazione RTDE
----------------------------------------
Cerca file di configurazione RTDE:
find ~/ros2_ws -name '*rtde*.yaml' -o -name '*rtde*.txt'

Riduci la frequenza di aggiornamento nei file di configurazione.

Opzione B: Usa configurazione headless
--------------------------------------
Avvia driver con headless_mode per ridurre carico:
ros2 launch ur_robot_driver ur_control.launch.py \
    ur_type:=ur5e \
    robot_ip:=192.168.10.194 \
    launch_rviz:=false \
    headless_mode:=true

PASSO 4: RIAVVIA DRIVER
------------------------
Dopo aver corretto errore compilazione e ridotto frequenza RTDE:

cd ~/MekoAiAccelerator/metodo_guida_pratica
./START_RAPIDO.sh

🔍 VERIFICA ERRORE COMPILAZIONE TEACH PENDANT
================================================================================

Errori comuni di compilazione:

1. **Sintassi errata nello script**
   - Verifica che tutti i comandi URScript siano corretti
   - Controlla parentesi, virgolette, punti e virgola

2. **Nodo External Control configurato male**
   - Verifica che Host IP sia corretto: 192.168.10.191
   - Verifica che Porta sia: 50002
   - Verifica che nodo sia nella struttura corretta

3. **Variabili non definite**
   - Se usi variabili nello script, assicurati che siano definite

4. **Programma troppo complesso**
   - Prova a creare programma minimale solo con External Control
   - Aggiungi altro codice dopo che funziona
