HOST IP (Host IP):
------------------
✅ INSERISCI: 192.168.10.191

Questo è l'IP della macchina remota dove gira il driver ROS2.
È l'IP che il robot deve usare per connettersi.

⚠️ IMPORTANTE:
- Deve essere ESATTAMENTE: 192.168.10.191
- Con PUNTI (.) non con spazi
- NO altri caratteri

HOST NAME (Host Name):
----------------------
✅ LASCIA VUOTO oppure inserisci: (lascia vuoto)

Il campo Host Name è opzionale. Puoi lasciarlo vuoto.
Se vuoi inserirlo, puoi usare l'hostname della macchina remota,
ma NON è necessario - basta l'IP!

PORTA (Port):
-------------
✅ INSERISCI: 50002

Questa è la porta su cui il robot ascolta per connessioni esterne.
Deve essere 50002 (porta standard per External Control).

TIMEOUT:
--------
✅ INSERISCI: 20 (o lascia default)

Timeout in secondi per la connessione.
