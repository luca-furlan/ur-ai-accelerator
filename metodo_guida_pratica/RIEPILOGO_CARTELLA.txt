🚀 COSA FARE ORA
================================================================================

PASSO 1: INSTALLA URCAP SUL ROBOT
----------------------------------
1. Copia "externalcontrol-1.0.5.urcap" su una chiavetta USB
2. Inserisci USB nel Teach Pendant del robot
3. Sul Teach Pendant: Installation → URCaps → +
4. Seleziona il file dalla USB
5. Riavvia il robot quando richiesto

PASSO 2: CONFIGURA PROGRAMMA SUL ROBOT
---------------------------------------
1. Crea nuovo programma sul Teach Pendant
2. Aggiungi nodo "External Control"
3. Configura:
   - IP Host: 192.168.10.191
   - Porta: 50002
4. Salva programma
5. Avvia programma (PLAY)

PASSO 3: COPIA SCRIPT SULLA MACCHINA REMOTA
-------------------------------------------
Opzione A - Via SCP (da PowerShell):
   scp -r metodo_guida_pratica lab@192.168.10.191:~/MekoAiAccelerator/

Opzione B - Via FileZilla/SFTP:
   - Connetti a: lab@192.168.10.191
   - Copia tutta la cartella in: ~/MekoAiAccelerator/

PASSO 4: ESEGUI SCRIPT SULLA MACCHINA REMOTA
---------------------------------------------
ssh lab@192.168.10.191
cd ~/MekoAiAccelerator/metodo_guida_pratica
chmod +x *.sh
./VERIFICA_SETUP.sh          # Verifica tutto
./SETUP_COMPLETO.sh          # Setup completo
