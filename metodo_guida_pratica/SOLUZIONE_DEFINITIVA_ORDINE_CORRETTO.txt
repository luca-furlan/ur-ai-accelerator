- Verifica programma è in PLAYING
- Verifica Host IP è VUOTO sul Teach Pendant
- Verifica Remote Control è abilitato

PASSO 4: AVVIA DRIVER ROS2 DOPO
---------------------------------
Dalla macchina remota:

Il driver si connetterà automaticamente al robot!

❌ ERRORI COMUNI
================================================================================

ERRORE 1: "Connection refused" sul Teach Pendant
--------------------------------------------------
CAUSA: Host IP NON è vuoto (es. Host IP = 192.168.10.191)
SOLUZIONE: Lascia Host IP VUOTO sul Teach Pendant

ERRORE 2: Robot non ha porta 50002 aperta
------------------------------------------
CAUSA: Programma non in PLAYING o Host IP non vuoto
SOLUZIONE: 
- Verifica programma è in PLAYING
- Verifica Host IP è VUOTO
- Verifica Remote Control è abilitato

ERRORE 3: Driver ROS2 non si connette
--------------------------------------
CAUSA: Robot non ha porta 50002 aperta quando driver si avvia
SOLUZIONE:
- Avvia programma sul robot PRIMA
- Verifica robot ha porta aperta (nc -zv)
- POI avvia driver ROS2

================================================================================
💡 PERCHÉ HOST IP VUOTO?
================================================================================

Host IP VUOTO significa:
- Il robot NON prova a connettersi
- Il robot APRE la porta 50002 e ASPETTA connessioni
- Il driver ROS2 (macchina remota) si connette AL robot

Questo è il comportamento standard quando il driver usa robot_ip!
