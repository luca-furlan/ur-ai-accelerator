================================================================================
🔴 CAUSA DEL SEGMENTATION FAULT
================================================================================

Possibili cause:
1. EtherNet/IP abilitato sul robot (occupa RTDE) - Issue #31
2. Conflitto RTDE (altri client RTDE attivi)
3. Problema con configurazione calibration
4. Versione driver incompatibile

Dal log vedo anche:
[ERROR] The calibration parameters of the connected robot don't match

Questo potrebbe causare problemi!

================================================================================
✅ SOLUZIONE
================================================================================

PRIMA DI TUTTO - Verifica sul Teach Pendant:

1. EtherNet/IP DISABILITATO (Installation → Fieldbus)
2. Remote Control abilitato (Settings → System → Remote Control)
3. Programma External Control configurato:
   - Host IP: 192.168.10.191
   - Port: 50002

POI - Risolvi segmentation fault:

1. Ferma tutto: pkill -f ur_robot_driver
2. Verifica EtherNet/IP disabilitato sul robot
3. Riavvia driver ROS2
