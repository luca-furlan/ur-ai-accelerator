COME AVVIARE LA WEB INTERFACE:
================================================================================

METODO 1: Via SSH (RACCOMANDATO)
---------------------------------

1. Apri PowerShell o Terminale

2. Connettiti all'AI Accelerator:
   ssh lab@192.168.10.191
   Password: easybot

3. Ferma eventuali web interface esistenti:
   pkill -f web_interface

4. Vai nella directory del progetto:
   cd ~/MekoAiAccelerator

5. Avvia la web interface:
   python3 -m remote_ur_control.web_interface

6. Lascia il terminale aperto e apri il browser su:
   http://192.168.10.191:8081

================================================================================
COSA VEDRAI NELL'INTERFACCIA:
================================================================================

Dopo aver avviato la web interface, vedrai una nuova sezione:

"🎮 Controllo Robot senza Teach Pendant"

Con questi pulsanti:
- ⚡ Power On
- 🔓 Brake Release  
- ▶️ Play
- ⏹️ Stop
- ⏸️ Pause
- 📂 Load Program (con campo di input)

================================================================================
COME USARE I CONTROLLI:
================================================================================

1. Power On: Accende il robot (se spento)

2. Brake Release: Rilascia i freni del robot

3. Play: Avvia il programma sul robot
   IMPORTANTE: Assicurati che ci sia un programma caricato

4. Stop: Ferma il programma in esecuzione

5. Pause: Mette in pausa il programma

6. Load Program: Carica un programma
   - Inserisci il nome (es: remote_control.urp)
   - Clicca "Carica"

================================================================================
NOTA IMPORTANTE:
================================================================================

Remote Control è già abilitato, quindi puoi usare direttamente i pulsanti
per controllare il robot senza bisogno del Teach Pendant fisico!

Alcune operazioni (come creare programmi) devono ancora essere fatte via VNC,
ma puoi avviare/fermare programmi esistenti direttamente dalla web interface.
